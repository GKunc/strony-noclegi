# Your website: how to change it

Your site is built so that you can change it by asking Claude in plain words. Every change is checked automatically before it goes online, so you cannot break the live site by accident.

## Getting started (once)
Open this project in Claude Code and say: **"set up my environment"**. Claude installs what is needed and shows you a live preview.

## Asking for changes
Just say what you want, for example:
- "Change the headline to …"
- "Add a question to the FAQ: … Answer: …"
- "Write a blog post about …"
- "Change the automatic email people get after the contact form"
- "Show me the page on a phone"

Claude shows you the change in the preview. When you are happy, say **"publish"**. A few minutes later it is live.

## What happens by itself
- Checks before every publish: broken links, missing texts, search engine tags, speed and accessibility. If something fails, Claude fixes it or asks you.
- A weekly health check of the live site. If something is wrong, the site owner gets an email.
- Search engines (Google, Bing, ChatGPT search) are told about new pages.

## Undoing a change
Say **"undo the last change"** or **"what did we change recently?"**. Nothing is ever lost; every version is kept.

## Facts only you know
Claude never makes up prices, numbers, testimonials or promises. If it needs one, it asks you. New business facts can be saved in `brief/landing.md` so they are remembered.
